The Project

About This Website

Introduction

TechPedia is an interactive, multi-page educational website developed as a micro project for the Foundations of Computing (GXEST203) course at Vidya Academy of Science and Technology, under APJ Abdul Kalam Technological University (KTU), 2024 scheme.

The website covers three core topics from the KTU S2 syllabus — Secondary Storage Devices, Instruction Format, and DNS (Domain Name System) — through structured content, visual diagrams, flowcharts, comparison tables, and interactive quizzes.

Built entirely with HTML5, CSS3, and vanilla JavaScript — no frameworks, no backend, no database. Everything runs directly in the browser.
